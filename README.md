# Desarrollo-y-despliegue-de-una-plataforma-de-videos-con-React-FastAPI-y-AWS-Objetivo
Desarrollar una Single Page Application (SPA) tipo plataforma de videos utilizando React, FastAPI, Amazon S3, Amazon EC2 y Amazon RDS.

La aplicación deberá permitir:

Registro e inicio de sesión de usuarios.

Publicación de videos.

Visualización dinámica de videos.

Reproducción de videos.

Comentarios.

Gestión de los videos del usuario.

La arquitectura deberá utilizar:

React + Vite para el frontend.

Amazon S3 (Frontend) para alojar la SPA.

Amazon S3 (Videos) para almacenar videos.

Amazon S3 (Miniaturas) para almacenar imágenes.

FastAPI en EC2 para la API.

Amazon RDS para la base de datos.
